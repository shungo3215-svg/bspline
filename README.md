# B-SPLINE STUDIO

Bスプラインで遊ぶ道具 5点。依存ゼロ、単一HTML。

| ファイル | 中身 |
|---|---|
| `index.html` | ランチャー（5本へのリンク＋オフライン化の入口） |
| `basis.html` | 基底とノット列で遊ぶ |
| `sequencer.html` | ノット列を時間で動かす |
| `duck.html` | しなる板と、通るBスプライン補間 |
| `weave.html` | 1本を群れに増やす |
| `surface.html` | テンソル積の曲面 |
| `bspline-studio.html` | 上の5本を同梱した1ファイル版（持ち歩き用） |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | オフライン化とホーム画面追加のため |

## 使い方は3通り

**1. Macでそのまま** — `index.html` をブラウザで開くだけ。

**2. iPadでオフラインアプリにする（推奨）**
1. このフォルダ一式を https で配信する（GitHub Pages / Cloudflare Pages など）
2. iPadのSafariでURLを開く。フッターのバッジが「オフラインで使えます」に変われば保存完了
3. 共有 → ホーム画面に追加

以降は機内モードでも、ホーム画面のアイコンからフルスクリーンで起動できる。
ネットが要るのは最初の1回だけ。

**3. iPad単体で完結させる** — `bspline-studio.html` 1ファイルをファイルAppに置き、
WorldWideWeb – Mobile などのローカルサーバーアプリでそのフォルダを配信する。
配信先が不要な代わりに、毎回アプリからの起動になる。

## 更新するとき

`sw.js` の `CACHE` の版番号を上げる。上げないと古いキャッシュが返り続ける。

```js
const CACHE = 'bspline-studio-v2';   // ← ここ
```

## 共通の核

5本とも同じ評価器を共有している（Cox–de Boor 基底 / de Boor 評価 / 解析微分 /
ベジェ分解）。分割の統一は 4e-16、ベジェ変換は次数3以下で誤差 3e-13 の厳密変換、
次数4以上は各スパン8分割で 0.05 単位未満。SVGはすべて3次ベジェで書き出す。
